Program Settings

This is a list of the less obvious areas on the program settings page as seen from left to right, top to bottom. You can see an image of the page itself here. If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Location

You can specify the tax either as a percentage, in which case the amount will be calculated, or an amount, in which case the program will calculate a tax rate rounded to the nearest 0.25% and if necessary calculate an adjustment (called a tax delta) amount to make the numbers add up.

Login

This area is used either to sign in to the Microsoft Azure cloud to save data to OneDrive or to sign out if you don't wish to connect to the cloud. If you are signed in it will show a little information about the signed in user.

The first time DivisiBill runs after being installed it will ask you to sign in so as to be able to check for existing data on line. You need not do so, use of the cloud is completely optional.

WiFi

DivisiBill automatically backs up changed items and lists to the cloud if it is enabled, setting this option limits backups to occur only when a WiFi connection is available so as to minimize the use of mobile data.

Diagnostics

Only use this area on the advice of DivisiBill Support.
