Program Settings

This is a list of areas on the program settings pages as seen from left to right, top to bottom, there are actually two alternative pages and this list applies to both. An image of the settings page for the Professional Edition is here or you can see an image of the page for the basic edition here. If you reached this list by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Title

This line tells you whether you are using the Basic edition or have purchased a professional upgrade and have additional features (OCR and cloud storage) enabled.

Location

This shows the current latitude and longitude of the place where the program thinks it is along with the estimated accuracy of that location. This is the value that will be used for the location of any new venue you create.

Defaults

This area allows you to set defaults for various things, DivisiBill will warn you if the current bill is not using these defaults. This is especially helpful to warn you when you base a new bill on an older one and inherit old values that are no longer correct.

Archive Button

Press this to create an archive file containing some program defaults and all the Bills, Venues and People currently saved.

Restore Button

Press this to find an archive created by "Archive" above and restore its contents, where an item of the same name already exists the restored one will be ignored. Optionally, you can elect to remove existing items before restoring new ones.

Delete All

Changes the behavior of the Restore button so it removes ALL existing items before restoring any. This option is dangerous - it can be used to remove all your local data, so be sure that is what you want before setting it.

Archive

If you are running the professional edition this allows you to specify whether or not to archive changed items to the cloud. The Basic Edition of DivisiBill cannot use cloud features of OCR scanning and automatic backup. For those features you'll need the Professional Upgrade. For more details see this page.

WiFi

This selection is available only in the professional edition. DivisiBill automatically backs up changed items and lists to the cloud if cloud access is enabled, setting this option limits backups to occur only when a WiFi connection is available so as to minimize the use of mobile data.

Upgrade

If you are running the basic edition this allows you to purchase a professional edition upgrade. The Basic Edition of DivisiBill cannot use cloud features like OCR scanning and automatic backup. For those features you'll need the Professional Upgrade. For more details see this page.

Status

In the professional Edition this shows you your order number and how many OCR scans you have remaining. In the basic edition this area is replaced by an "Upgrade to Professional" button.

Scans

The Professional Edition of DivisiBill can use cloud based OCR scanning to extract information from a picture of a printed bill. Each scan is charged and when the number remaining reaches zero you must buy more before another scan will be allowed. For more details see this page.

Diagnostics

Only use this area on the advice of DivisiBill Support.
