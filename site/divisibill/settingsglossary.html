Program Settings

This is a list of areas on the program settings pages as seen from left to right, top to bottom, part of the page looks different depending on purchases you can make but this list describes all the options. An image of the settings page after purchasing a Professional Subscription and some OCR scans is here or you can see an image of the page for the basic edition here. If you reached this list by tapping one of the active areas in one of those page images, the relevant heading should be highlighted below.

Title

This line tells you whether you are using the Basic Edition or have purchased a professional subscription and have cloud storage capabilities.

Location

This shows the current latitude and longitude of the place where the program thinks it is along with the estimated accuracy of that location. This is the value that will be used for the location of any new venue you create or any venue you use that doesn't currently have a location.

Defaults

This area allows you to set defaults for various things, DivisiBill will warn you if the current bill is not using these defaults. This is especially helpful to warn you when you base a new bill on an older one and inherit old values that are no longer correct (like an outdated tax rate).

Archive Button

Press this to create an archive file containing all the Bills, Venues and People currently saved as well as selected program defaults. By using a cloud storage app like Microsoft OneDrive or Google Drive you can store archives in the cloud for free with as much or as little encryption as you like. There are also a number of free Android file management apps (Total Commander for example) that will permit archives to be saved locally, which is fast, but offers no protection against system failure.

Restore Button

Press this to find an archive created by the "Archive" button and restore its contents, where an item of the same name already exists the restored one will be ignored. Optionally, you can elect to remove all existing items before restoring any new ones (see "Delete All").

Delete All Switch

Changes the behavior of the Restore button so it removes ALL existing items before restoring any. This option is dangerous - it can be used to remove all your local data, so be sure that is what you want before setting it.

Backup Switch

If you are running the Professional Edition this allows you to specify whether or not to automatically back up changed items to the cloud. The Basic Edition of DivisiBill cannot use cloud backup. For more details see this page.

WiFi Switch

This selection is available only in the Professional Edition. If you choose to permit it by setting "Archive", DivisiBill automatically backs up changed items and lists to the cloud if cloud access is enabled, setting this option limits backups to occur only when a WiFi connection is available so as to minimize the use of mobile data.

Modify Button

If you have a Professional Subscription this button opens up a web site to permit you to view, modify or cancel it.

Subscribe

This allows you to purchase a Professional Edition subscription to allow DivisiBill to use cloud backup, without it you should use manual archive/restore instead. For more details see this page.

Status

This shows you your Pro Subscription order number. In the basic edition this area is replaced by the "Subscribe" button which allows you to purchase a Professional subscription.

Scans

All versions of DivisiBill can use cloud based OCR scanning from the image page to extract information from a picture of a printed bill by purchasing "scans". Each scan is charged and when the number remaining reaches zero you must buy more before another scan will be allowed. For more details see this page. Depending whether you have scans remaining this area will show an order number or a button to order more.
