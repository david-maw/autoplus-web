Program Settings

This is a list of areas on the program settings pages as seen from left to right, top to bottom, there are actually two alternative pages and this list applies to both. An image of the settings page for the Professional Edition is here or you can see an image of the page for the basic edition here. If you reached this list by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Title

This line tells you whether you are using the Basic edition or have purchased a professional upgrade and have additional features (OCR and cloud storage) enabled.

Location

This shows the current latitude and longitude of the place where the program thinks it is along with the estimated accuracy of that location. This is the value that will be used for the location of any new venue you create.

Defaults

This area allows you to set defaults for various things, DivisiBill will warn you if the current bill is not using these defaults. This is especially helpful to warn you when you base a new bill on an older one and inherit old values that are no longer correct.

Upgrade

If you are running the basic edition this allows you to purchase a professional upgrade. The Basic Edition of DivisiBill cannot use cloud features like OCR scanning and automatic backup. For those features you'll need the Professional Upgrade. For more details see this page.

Login

This area is available only on the professional edition, it is used either to sign in to the Microsoft Azure cloud in order to save data to OneDrive, or to sign out if you don't wish to remain connected to the cloud. If you are signed in it will show a little information about the signed in user.

The first time DivisiBill professional runs after being installed it will ask you to sign in so as to be able to check for existing data on line. You need not do so, use of the cloud is completely optional.

WiFi

This selection is available only in the professional edition. DivisiBill automatically backs up changed items and lists to the cloud if cloud access is enabled, setting this option limits backups to occur only when a WiFi connection is available so as to minimize the use of mobile data.

Scans

The Professional Edition of DivisiBill can use cloud based OCR scanning to extract information from a picture of a printed bill. Each scan is charged and when the number remaining reaches zero you must buy more before another scan will be allowed. More more details see this page.

Diagnostics

Only use this area on the advice of DivisiBill Support.
