Image Glossary

This is a list of the important areas on the image page as seen from left to right, top to bottom. You can see an image of the page itself here. If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Icons

These appear in the toolbar at the top of the page or in the area revealed when you swipe on a participant line.

Flyout ()

This icon, in the top left corner of the screen, allows you to show, or collapse, the flyout menu allowing navigation to other pages (navigate from the items page to the totals page by swiping left, back by swiping right).

Camera (ﴹ)

Opens the camera app so you can take a picture of the bill.

Load Image (亮)

Allows you to browse through existing images to select one to use for the bill..

OCR (󰅥)

Uses a web service in the cloud to scan the image to create input for the current bill.

Delete (啕)

Removes the association between the current image and the current bill.

Image Area

This is where the image will be displayed once it has been processed (converted to gray scale and reduced in size).
