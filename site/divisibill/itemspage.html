Items Page

This is where the individual items and the information about them is entered, either manually or by scanning a paper bill. It looks something like this (hover over the image for more information)

Comp

Sometimes items will be "comped" by a restaurant, usually by way of an apology because because something went wrong. Clicking in this column allows you to toggle the Comped status of an item (comped items are free, but still contribute to the tip. If you don't want a comped item to contribute to the tip either, just set the cost to zero, or delete the item altogether).

Icons

Select one of the icons on the top right of the page to send a copy of the bill by mail(󰄈), show items for all or only one person(/), add an additional item () or delete all items (啕).

Line Items

You can swipe individual items left or right, swipe left deletes the item (if you delete an item by mistake you can get it back until you exit the page). Click on a line to make that the current one so you can edit the item name or price.

Open Flyout

This icon(), in the top left corner of the screen, allows you to show, or collapse, the flyout menu allowing navigation to other pages (navigate from the items page to the totals page by swiping left, back by swiping right).

Sharing Control

Click here to remove the item assignments if there are any, if there are none, it will share the item cost in the same proportion as the rest of the bill so far, you can repeat this once the whole bill has been allocated if you want to make it more representative, alternatively, you can designate how the comped amount is shared manually, just as for any other amount although in the comped case only the tip is shared since the other amounts (cost and tax) are zero.

Venue Name

This is the name of the current venue, click on it to see the details of the current bill, double click to select a new venue from a list.
