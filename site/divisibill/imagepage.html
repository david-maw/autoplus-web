Image Page

This is where you go to take a picture of the bill (or load it from a file). If you have upgraded to the pro version you can also scan it to extract the data using OCR (optical character recognition). The scanning is actually done by a web service so to minimize the amount of irrelevant data that is sent DivisiBill first converts an imported picture to gray scale and a lower resolution.

Tap on a highlighted area to see what it does (on a desktop browser you can also hover over an area to see its name).
