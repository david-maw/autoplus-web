Item Selected

This is a list of the controls that are shown when an item is selected as seen from left to right, top to bottom. A selected item will be highlighted, click on the item description to deselect it.

If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below, if not, you can see an image of the page here.

Share Information

The name of the person represented by the selected button and the number of shares they have. This area shows up only after a long press of one of the participant buttons is performed.

Share Selector

Tap the corresponding button to indicate the number of shares you would like this person to have. This area shows up only after a long press of one of the participant buttons is performed.

Participant 1

A button with rounded corners indicating that it represents more than one share, press and hold to see, or change, how many shares are allocated to it. Like the other participant buttons it contains the name of the person it represents.

Participant 2

A button with square corners indicating that it represents one share, press and hold to see, or change, how many shares are allocated to it. Like the other participant buttons it contains the name of the person it represents.

Participant 3

A button with no border indicating that it represents no shares, press and hold to see, or change, how many shares are allocated to it. Like the other participant buttons it contains the name of the person it represents.

Description

This is the description of the current item, it can be arbitrarily long but only the start of it appears in the list above.

Cost

The cost of this item (without tax or tip).
