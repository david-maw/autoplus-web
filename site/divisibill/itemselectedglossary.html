Item Selected

This is a list of the controls that are shown when an item is selected as seen from left to right, top to bottom. You can see an image of the page itself here. If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Participant 1

A button with rounded corners indicating that it represents more than one share, press and hold to see, or change, how many shares are allocated to it). Like the other participant buttons it contains the name of the person it represents.

Participant 2

A button with square corners indicating that it represents one share.

Participant 3

A button with no border indicating that it represents no shares.

Description

This is the description of the current item, it can be arbitrarily long but only the first few characters appear in the list above.

Cost

The cost of this item (without tax or tip).
