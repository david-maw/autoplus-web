Information Page

This is actually a collection of several pages, the About Page is the most complex. It looks something like this.

Tap on a highlighted area to see what it does (on a desktop browser you can also hover over an area to see its name).

The other two pages are:

  • Release Notes

    This contains a list of highlights of the changes in the current and previous releases.

  • Report a Problem

    This offers a text page already populated with some data into which you can enter problem information and have a mail message to DivisiBill support created.

They can be selected using the tab bar at the bottom of the page.
