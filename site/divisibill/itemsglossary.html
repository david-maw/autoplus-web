Items Glossary

This is a list of the important areas on the items page as seen from left to right, top to bottom. You can see an image of the page itself here. If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Icons

These appear in the toolbar at the top of the page or in the area revealed when you swipe on a participant line.

Flyout ()

This icon, in the top left corner of the screen, allows you to show or collapse the flyout menu allowing navigation to other pages (navigate from the items page to the totals page by swiping left, back by swiping right).

Mail (󰄈)

Sends mail containing information about the bill overall, not personalized to any specific participant.

Filter ()

Cancels filtering for a particular person if it is in use or filters based on the first person assigned to the selected item (if there is one).

Add ()

Adds a new item to the bill and selects it so you can edit the description, amount and assignment to participants.

Delete (啕)

Deletes all items (you can undo this if you do it by mistake). To delete a single item swipe left on that item.

Venue Name

This is the name of the current venue, tap on it to see the properties (tax and tip rates, for example) of the current bill, double tap to select a new venue from your list.

Sharing Control

Tap here to remove the item assignments if there are any, if there are none, tapping will share the item cost in the same proportion as the rest of the bill so far. You can repeat this once the whole bill has been allocated if you want to make it more representative, alternatively, you can designate how the amount is shared manually just as for any other amount. For comped items only the tip is shared since the other amounts (cost and tax) are zero.

This column will be blank for an unshared item, contain a circled digit (1,2...8,9,0) for an item assigned to only one participant, a plus sign for items assigned to more than one participant and an asterisk if the item is shared unequally between assignees.

Comp

Sometimes items will be "comped" by a restaurant, usually by way of an apology because something went wrong. Clicking in this column allows you to toggle the Comped status of an item, denoted by ☺ (a smiley face icon). comped items are free, but still contribute to the tip. If you don't want a comped item to contribute to the tip, just set the cost to zero, or delete the item altogether.

Line Items

You can swipe individual items left to delete them (if you delete an item by mistake you can get it back until you exit the page). Tap on an item to make that the current one so you can edit the name or price and/or assign it to one or more participants.
