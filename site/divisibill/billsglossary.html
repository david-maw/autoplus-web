Items Glossary

This is a list of the important areas on the items page as seen from left to right, top to bottom. You can see an image of the page itself here. If you reached this page by tapping one of the active areas in the page image, the relevant heading should be highlighted below.

Icons

These appear in the toolbar at the top of the page or in the area revealed when you swipe on a participant line.

Flyout ()

This icon, in the top left corner of the screen, allows you to show or collapse the flyout menu allowing navigation to other pages.

Sort ()

Sorts the list of bills by age, name, or distance of the bill venue from your current location (venues with unknown locations sort last).

Filter ( / )

Selects only the most recent bill from each location. Shows a filled in icon when it is set.

Show Local (󰃡 / 󰃠)

Shows bills stored locally. Shows a filled in icon when it is set.

Show Cloud ( / )

Shows bills stored remotely (in cloud storage). Shows a filled in icon when it is set.

Bill

This is one of the areas representing bills, each area represents a single bill. You can swipe it left to delete a copy of the bill (if both local and remote ones are shown it will delete the loal one), or swipe right to make it the current bill (which may save the previous bill if it has been changed). The current bill never shows in this list.

Tapping on a bill will show a quick summary of it.

Location

This column shows where the bill is stored, either locally(󰃡), in the cloud (), or both. If it stored in the cloud tapping in this column will download it.

If cloud access is allowed but you are not currently showing remote (cloud resident) bills the local bills will still show an indication of whether they are also stored in the cloud or not.
