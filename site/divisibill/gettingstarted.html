Getting Started With DivisiBill

When you first run DivisiBill it will start up with some sample data. A fake bill for "Queasy Diner" shared unevenly between 3 people and some supporting data. However,on the first run before it can do anything else the app will ask for some permissions.

The first permission requested will be access to photos and media (which allows it to load bill images for scanning). Then it will ask for access to your location in order to figure out whether you're in a venue you have already stored. Finally it will ask you to log in to the Microsoft Azure cloud in order to store and retrieve data from OneDrive. All these are optional, the app works without them, but they all add capabilities to the app.

The first thing you'll see is the Items page which will contain a half dozen typical items you might find on a restaurant bill. An appetizer that's shared equally, meals for each participant, wine shared unequally and finally a discount, shared equally.

You can get an idea of how each item is shared by looking in the left column, where there are different symbols for each class of sharing, but to understand (or change) the details of how an item is shared you have to select the item (just tap on it). When an item is selected detailed information for that item will be shown at the bottom of the page.

To see the results of the sharing swipe left on any empty space or the name of the venue and that will take you to the Totals page. It lists the participants and the amount each one will pay along with details for the whole bill at the bottom of the page. Swipe right on any empty area or the name of the venue to return to the items page.

There are many other pages in DivisiBill (see the index) but they exist in support of these two.

General User Interface

In general pages are either a lot of individual values or lists of items. With lists of items you can swipe individual items from lists of purchased items, participants and so on) left or right, swipe left deletes the item (you can usually get it back if you delete an item by mistake). Other actions are tap, press and hold, or, occasionally, double tap.

The operating system "back" button returns to the previous page or the Totals or Items page if there is no previous page. On the Items or Totals page, the "back" button exits the program.

In general exiting DivisiBill and returning to it has no effect, the current bill is simply reloaded. If you leave a bill unchanged for more than a couple of hours it is saved next time the program starts up and a new bill (initially with the same content as the previous one) is started. If you choose to reload a saved bill and the current bill is not saved, it will be, there's no need to explicitly save a bill.
