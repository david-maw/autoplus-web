Welcome

When you first run DivisiBill after installation it will start by showing you this "Welcome" text. After you exit from the help system DivisiBill will show the startup screen (illustrated below) which will check for the optional professional edition.

If you have already purchased the professional edition DivisiBill will show a "Cloud Access" pop-up to ask whether you want to enable cloud storage. Cloud storage is disabled by default, but if you already have DivisiBill data stored in the cloud, enabling it at this point will permit the newly installed DivisiBill to automatically reload your most recent lists of venues and people. You can enable cloud storage later Once cloud storage is enabled individual bills be used from the cloud or copied locally, or former lists of people or venues may be downloaded.

Next it will show a pop-up asking for access to your location in order to figure out whether you're at a venue you have already stored. The app will work without this "location" permission but it will be unable to guess where you are and look for existing bills for that venue.

After the permission dialogs you will see the whole startup screen, which looks like this:

The progress indicator will spin and the Status information will be updated as initialization progresses. Once initialization has been completed (typically a few seconds) you'll see the Items page which will contain a bill. If no existing bill is suitable DivisiBill loads up a fake one for "Queasy Diner" with a half dozen typical items you might find on a restaurant bill. The items include an appetizer that's shared equally, meals for each participant, wine shared unequally and finally a discount shared equally.

You can get an idea of how each item is shared by looking in the left column, where there are different symbols for each class of sharing, but to understand or change the details of how an item is shared you must select the item by tapping on it. When an item is selected detailed information for that item will be shown at the bottom of the page where it can be changed.

To see the results of the sharing swipe left on any empty space or the name of the venue and that will take you to the Totals page. That page lists the participants and the amount each one will pay, along with details for the whole bill at the bottom of the page. Swipe right on any empty area or the name of the venue to return to the Items page.

There are many other pages in DivisiBill (see the index) but they exist in support of these two.

General User Interface Hints

Most pages are either a lot of individual values, or lists of purchased items, participants and so on. You can select a page using the flyout menu that pulls out from the left of each main page. You can also open the flyout by clicking on the hamburger icon () at the top left corner of the page.

With lists you can usually swipe individual items left or right, swipe left deletes the item (you can usually get it back if you delete an item by mistake). Other actions are tap, press and hold, or, occasionally, double tap.

The operating system "back" button returns to the previous page or the Totals or Items page if there is no previous page. If you are already on the Items or Totals page, the "back" button exits the program.

If you close DivisiBill and return to it later it will open the bill you were working on. If you leave a bill unchanged for more than a couple of hours it is saved next time the program starts up and a new bill with the same content as the previous one is started (you can see creation and update times in the Bill Properties page). If you choose to reload a saved bill and the current bill is not saved, it will be, there's no need to explicitly save a bill except in the rare case where you want to start a brand new bill within a couple of hours. DivisiBill would just keep editing the old bill in that case, overwriting your saved data, so you have to tell it when you want to start a new bill.
