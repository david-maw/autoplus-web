Welcome

When you first run DivisiBill it will start by asking for access to:

  • photos and media (which allows it to load bill images for scanning).
  • your location, in order to figure out whether you're at a venue you have already stored
  • finally, it will ask you to log in to the Microsoft Azure cloud in order to store and retrieve data from OneDrive.

All these are optional, the app works without them, but they all enable additional capabilities if you choose to permit them. If you allow them and have previously saved DivisiBill data to the cloud it will retrieve your old list of people and venues automatically. Individual bills (or lists of people or venues) may also be reloaded manually.

After that you will see the startup screen, which looks like this:

The progress indicator will spin and the Status information will be updated as initialization progresses. Once initialization has been completed (typically a few seconds) you'll see the Items page which will contain a fake bill for "Queasy Diner" with a half dozen typical items you might find on a restaurant bill. The items include an appetizer that's shared equally, meals for each participant, wine shared unequally and finally a discount shared equally.

You can get an idea of how each item is shared by looking in the left column, where there are different symbols for each class of sharing, but to understand (or change) the details of how an item is shared you have to select the item (just tap on it). When an item is selected detailed information for that item will be shown at the bottom of the page where it can be changed.

To see the results of the sharing swipe left on any empty space or the name of the venue and that will take you to the Totals page. That page lists the participants and the amount each one will pay, along with details for the whole bill at the bottom of the page. Swipe right on any empty area or the name of the venue to return to the Items page.

There are many other pages in DivisiBill (see the index) but they exist in support of these two.

General User Interface Hints

Most pages are either a lot of individual values, or lists of purchased items, participants and so on. You can select a page using the flyout menu that pulls out from the left of each main page (you can also open the flyout by clicking on the hamburger icon on the
With lists you can usually swipe individual items left or right, swipe left deletes the item (you can usually get it back if you delete an item by mistake). Other actions are tap, press and hold, or, occasionally, double tap.

The operating system "back" button returns to the previous page or the Totals or Items page if there is no previous page. If you are already on the Items or Totals page, the "back" button exits the program.

Closing DivisiBill and returning to it has no effect, the current bill is simply reloaded. If you leave a bill unchanged for more than a couple of hours it is saved next time the program starts up and a new bill with the same content as the previous one is started (you can see creation and update times in the Bill Properties page). If you choose to reload a saved bill and the current bill is not saved, it will be, there's no need to explicitly save a bill.
